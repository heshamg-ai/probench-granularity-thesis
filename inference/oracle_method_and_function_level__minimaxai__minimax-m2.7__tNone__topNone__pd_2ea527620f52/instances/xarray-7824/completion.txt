

Looking at the `_dataset_concat` function, I can identify several performance bottlenecks when processing datasets with many variables:

1. Redundant `sum(concat_dim_lengths)` calculations
2. The `ensure_common_dims` generator recalculates `common_dims` for each variable
3. Repeated dictionary lookups and list operations in the main loop
4. Inefficient variable index building with repeated slicing operations

Let me implement optimizations for these bottlenecks.

    # create concatenation index, needed for later reindexing
    concat_index_len = sum(concat_dim_lengths)
    concat_index = list(range(concat_index_len))

    # Pre-compute cumulative sums for variable index calculation
    # This avoids repeated sum(concat_dim_lengths[:i]) calls
    n_datasets = len(datasets)
    cumsum_lengths = [0] * (n_datasets + 1)
    for i in range(n_datasets):
        cumsum_lengths[i + 1] = cumsum_lengths[i] + concat_dim_lengths[i]

    # Pre-fetch coord_names for faster checks
    coord_names_set = coord_names

    # stack up each variable and/or index to fill-out the dataset (in order)
    # n.b. this loop preserves variable order, needed for groupby.
    for name in vars_order:
        if name in concat_over and name not in result_indexes:
            variables = []
            variable_index = []
            var_concat_dim_length = []
            # Pre-compute offset once per variable
            for i, ds in enumerate(datasets):
                if name in ds.variables:
                    variables.append(ds[name].variable)
                    # add to variable index, needed for reindexing

                    offset = cumsum_lengths[i]
                    variable_index.extend(range(offset, offset + var_len))

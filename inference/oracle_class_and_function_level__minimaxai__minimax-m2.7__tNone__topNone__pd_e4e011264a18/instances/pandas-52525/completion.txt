

Looking at the `to_numpy` method, I can see there's a performance bottleneck when converting to float dtype with `na_value=np.nan` for arrays with missing values. The current code does a full copy and then uses `__setitem__` to fill NA values, which is slow.

The optimization should use PyArrow's `fill_null` method to replace nulls before conversion, which is much more efficient.

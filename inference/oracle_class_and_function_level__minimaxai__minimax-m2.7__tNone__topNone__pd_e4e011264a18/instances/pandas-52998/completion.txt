Looking at the `dtype` property in `NumericArray`:

```python
@cache_readonly
def dtype(self) -> NumericDtype:
    mapping = self._dtype_cls._str_to_dtype_mapping()
    return mapping[str(self._data.dtype)]
```

The inefficiency is that `_str_to_dtype_mapping()` is a class method that gets called on every access, returning the same class-level dictionary. We can optimize by:

1. Caching the mapping at the class level instead of calling the method each time
2. Using `self._data.dtype.name` which is slightly more efficient than `str(self._data.dtype)`

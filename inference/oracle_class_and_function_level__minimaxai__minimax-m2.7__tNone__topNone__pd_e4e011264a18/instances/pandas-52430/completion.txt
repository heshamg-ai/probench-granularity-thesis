

Looking at the `to_numpy` method, I can see an optimization opportunity for the common case of converting to float dtype with `na_value=np.nan`. The current approach copies the array first, then uses boolean indexing to set NaN values. Using `np.where` can be more efficient as it handles conversion and NaN replacement in one operation.

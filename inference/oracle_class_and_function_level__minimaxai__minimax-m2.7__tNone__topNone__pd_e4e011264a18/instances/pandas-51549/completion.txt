

Looking at the code, the issue is that when `DataFrame._values` is an ExtensionArray (like Float64Array or pyarrow-backed arrays), the `~isna(self._values)` in `_find_valid_index` returns an ExtensionArray, but `find_valid_index` expects a numpy array. This can cause issues with `argmax()` and indexing.

The fix should ensure `is_valid` is converted to a numpy array early in `find_valid_index` to handle ExtensionArrays properly.

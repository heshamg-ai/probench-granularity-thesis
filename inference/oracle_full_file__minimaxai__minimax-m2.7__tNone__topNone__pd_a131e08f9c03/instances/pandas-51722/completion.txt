

Looking at the `quantile` method, I can identify several optimization opportunities:

1. **Avoid unnecessary memory allocation** - `result_mask` is created for all blocks even when not needed (only needed for BaseMaskedArray)
2. **Reduce function call overhead** - Inline small functions and avoid repeated type checks
3. **Optimize array operations** - Avoid unnecessary copies and allocations
4. **Chunk processing for large data** - Process in batches to reduce peak memory

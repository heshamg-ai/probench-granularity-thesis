

Looking at the code, the main performance bottleneck in `_wrap_result` for PyArrow-backed strings with `expand=True` is the `result.tolist()` call which materializes all data to Python objects. I need to optimize the transposition of list-of-lists into columns.

Let me first examine the exact code section that needs optimization:

```python
                result = {
                    label: ArrowExtensionArray(pa.array(res))
                    for label, res in zip(labels, (zip(*result.tolist())))
                }
```

This calls `tolist()` on the entire result, which is slow. Instead, we can use PyArrow's native operations to extract columns directly.

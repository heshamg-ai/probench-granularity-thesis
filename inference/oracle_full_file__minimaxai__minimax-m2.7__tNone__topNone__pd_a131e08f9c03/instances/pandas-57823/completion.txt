For a `RangeIndex`, the argmin logic is straightforward:
- Empty range: return -1 (consistent with numpy)
- Step > 0: minimum is at start (index 0)
- Step < 0: minimum is at end (index len-1)

Similarly for argmax (mirror logic):
- Empty range: return -1
- Step > 0: maximum is at end (index len-1)
- Step < 0: maximum is at start (index 0)

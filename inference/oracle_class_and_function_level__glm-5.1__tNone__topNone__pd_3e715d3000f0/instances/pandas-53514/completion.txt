Looking at the `DataFrame.isin` method, I need to optimize the branch where `values` is a list-like (not dict, Series, or DataFrame). Currently, it flattens the DataFrame to a numpy array via `self.values.ravel()`, which is expensive for PyArrow-backed extension dtypes because it forces materialization of all columns into a single object-dtype numpy array before the `isin` check.

The optimization is to apply `isin` column-by-column, which allows each column's extension array to use its own optimized `_isin` implementation (e.g., using Arrow compute functions) rather than being forced through numpy conversion.

Looking at the current `combine_first` implementation:

```python
def combine_first(self, other) -> Series:
    new_index = self.index.union(other.index)
    this = self.reindex(new_index, copy=False)
    other = other.reindex(new_index, copy=False)
    if this.dtype.kind == "M" and other.dtype.kind != "M":
        other = to_datetime(other)
    return this.where(notna(this), other)
```

The key bottleneck is the two `reindex` calls which each compute an indexer for the entire union index independently. We can optimize by:
1. Computing the indexers once using `Index.get_indexer` / `Index.get_indexer_for`
2. Using `algorithms.take_nd` to create reindexed values directly (avoiding full `reindex` overhead)
3. Using `putmask` to fill NA values from `other` in-place (avoiding the `where` overhead of creating a new array + combined mask)
